# Real browser acceptance

This driver runs the actual production browser bundle and actual WebRTC connections. The current user-authorized acceptance scope is Chrome only. It uses Playwright 1.63.0 with an independently downloaded Chrome for Testing, records the running version, and saves it with every result. No mock domain, projected HTTP entity service, native mediator, video tablet, or hardware GPU is involved. Earlier Firefox155/156 software smoke results are historical evidence only; they are not repeated or included in current acceptance.
