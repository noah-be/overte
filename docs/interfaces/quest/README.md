# Overte for Meta Quest

> [!CAUTION]
> This is an AI-assisted, experimental, and currently paused port. It has no
> current physical-headset acceptance evidence and must not be treated as a
> supported build or release.

## Current status

The Quest source and historical evidence are preserved on
`android-vr-quest`. Parent-branch synchronization keeps repository policy and
shared fixes intact; it does not mean that Quest product development is active.

Quest is paused because no authorized physical test headset is currently
available and virtual or simulated testing is too costly and indirect for the
required runtime decisions. Pico 4, Android Phone, and then iPad have priority.

## Support boundary

| Area | Current status |
| --- | --- |
| Product branch | `android-vr-quest` |
| Physical target | No named or authorized headset currently available |
| Virtual target | Not accepted as a substitute for headset evidence |
| Development | Paused at `QUEST-Q0` |
| Distribution | Out of scope while paused |
