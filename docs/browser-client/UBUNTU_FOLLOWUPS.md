# Ubuntu native-journey prerequisites and unresolved capabilities

The first hosted run failed while building the native-input extension because the signed Ubuntu GL development header package was absent (`GL/gl.h`). Add `libgl-dev` to the existing development dependency install. This is a dependency correction; it does not establish successful native runtime tests.

The same run's actual sandbox tests refused UID-map setup. Before changing policy, capture only the targeted `apparmor-diagnostic.py` report. Inspect the exact installed package versions, `/usr/bin/bwrap` and `/usr/bin/unshare` attachment, package-owned profile bytes, disabled markers and loaded matching profiles. The diagnostic is read-only and does not accept namespace failure as success.

Ubuntu's Noble packaging changelog lists `bwrap-userns-restrict` in `apparmor` and `unshare-userns-restrict` in `apparmor-profiles`. On the ephemeral runner, install the signed `apparmor-profiles` package if absent. If the actual package-owned policy is missing or inactive, reload only those exact shipped profiles after validating ownership and confirming they have not been disabled or locally replaced. Preserve the packaged profile's confined child restrictions. Do not overwrite it with a broadly unconfined profile. Then repeat the unchanged kernel/worker boundary preflight and real tests. A remaining refusal is a failed capability check, requiring review of actual policy diagnostics. No fallback may disable AppArmor globally, change restriction sysctls, run the tests as root, disable the browser sandbox, remove boundary assertions or skip the native journey.

The default rootless Ubuntu container's normal seccomp and namespace restrictions also refused user namespaces. It separately started authenticated Xvfb and private null PulseAudio, but native Qt initialization failed. Six-target ELF closure, including `libqxcb.so`, had passed; this does not validate dynamically selected plugins or display authentication. Run the frozen independent probe through `debug-plugins.py`, which adds only `QT_DEBUG_PLUGINS=1`, bounded inspection of all staged plugins and sanitized exact dependency/display categories. Never infer a missing library from the generic Qt plugin error alone. The container result cannot stand in for the actual hosted runner's kernel or AppArmor policy.

The audio harness also had a concrete missed-event race: completion listeners were attached to a nine-second injector after awaiting output capture. Store child completion immediately and always stop the owned process and mute native audio in `finally`. The new helper preserves signal and tone assertions and bounds injector lifetime, with six real child-process tests. These tests establish process ownership, not browser/native voice transmission; the actual domain journey remains required.

Sources: [Ubuntu namespace restriction explanation](https://discourse.ubuntu.com/t/understanding-apparmor-user-namespace-restriction/58007), [Noble package changelog naming both shipped profiles](https://lists.ubuntu.com/archives/noble-changes/2024-June/039347.html).
