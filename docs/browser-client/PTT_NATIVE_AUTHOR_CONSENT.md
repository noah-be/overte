# PTT reverse audio author consent

The PTT runner's original 997 Hz reverse-audio assertion was reached with the independent native author still muted. The pinned author starts `Audio.muted = true`; its existing local command loop changes that state only for an explicit boolean command. The existing core journey unmutes this author before the same tone injection and restores mute afterward. This packet changes that prerequisite, preserving the RMS and frequency assertions, genuine PTT controls, baseline seven entities, and all existing timeouts.

The test operator must provide `OVERTE_PTT_AUTHOR_ROOT` as the canonical repository containing the **already running managed lab**, alongside the existing matching `OVERTE_PTT_NATIVE_PULSE`. The PTT runner may belong to a private source copy; it must not infer the author's command directory from its own repository. No process starts, reprovisioning, pose changes, entity mutations, or public-world use are added.

The helper admits the existing native and asset-HTTP records only after checking PID/start ticks, owned process group, live state, actual working directory, executable and argument agreement, exact local author URL/domain, and exact HTTP directory/port. It holds directory/file descriptors without following aliases, rejects FIFOs and writable-by-other files, verifies the pinned authored script and its optional exact full/passive diagnostics prelude, and requires the served script to predate the native launch. These checks attest the admitted served source; they are not an introspection of already executed QtScript memory.

A private exclusive command lease prevents two copies of this helper from using the author at once. Other integration runners must remain serialized by the parent operator. The only written command fields are `sequence` and `muted`; the sequence exceeds the prior command, observed applied sequence, and current wall clock. A command succeeds only after both its exact native `command-applied` record and a fresh, later independent mute observation. Each original fifteen-second command deadline is unchanged. Raw native logs remain private; only fixed booleans and source hashes enter the PTT report.

Mute restoration precedes other cleanup and is confirmed independently. Failure remains a failed test. Failed restoration is not silently retried. Descriptor/lease cleanup still occurs, and a surviving unmuted peer is reported rather than hidden. An abrupt test-process death may leave the private lease file; its recorded PID/start ticks require operator identity review before removal.
