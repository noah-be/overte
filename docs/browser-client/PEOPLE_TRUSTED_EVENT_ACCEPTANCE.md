# People physical-event proof ownership

This fixture-only candidate replaces the cross-RPC stale calibration model in the genuine two-visitor People harness. It does not change `BrowserTablet`, gateway input admission, native input, frame ACKs, capture cadence, native People behavior, participant rendering or mixer behavior. The earlier queue/CAS packet and its actual failures remain preserved; this proposal is not actual browser acceptance.

A physical driver click may occur after a newer periodic frame is drawn. The application legitimately binds its pointerdown synchronously to that current displayed frame. Requiring an earlier Node witness to remain current across later RPCs can therefore reject a valid application event. The new observer instead requires a freshly qualified native control and painted pixels at the trusted physical event itself, and then verifies the application's actual outgoing press and release. It never accepts the old witness as evidence for a missing current record.

## Native and event admission

The existing held-FD worker-log reader and exact native parser project at most 32 validated records, with a combined UTF-8 bound of `32 * (16384 + 256)` bytes. Only this validated projection enters the browser, where the same serialized parser validates it again. Raw worker logs never enter the page. The copied QML observer remains passive. It adds only a unique enabled native PEOPLE Home-button record, matched by text, original sort order 7 and native button properties. The reviewed packaged `system/pal.js` SHA-256 is `6a40c7b1f039e4cb71fd90719a8cd425b3cb0660443c01f17a01126834a99e34`; its original PEOPLE button routes to `hifi/Pal.qml`. This is a source reference, not proof that every source-mirror QML byte is the packaged RCC byte.

The existing nearby guest predicate, unique private peer UUID, native/model/checkbox Ignore state, enabled/visible ancestry, no truncation and exact sequence/revision/navigation remain mandatory. At document capture phase, before the unchanged canvas target handler, the observer requires an actual trusted left-pointer event on the owned canvas. In that same synchronous turn it checks the current frame, current native record, unchanged control layout, connected/visible authority and original painted-control oracle. Contrast remains greater than 20, the ROI remains at least 8 by 8 and at most 65,536 pixels, and all native screen/canvas bounds remain strict.

The observer cannot dispatch input, focus controls, prevent events, change DOM/native properties, ACK a frame or send a packet. The existing WebSocket fixture observes the application's original outgoing packets. Both press and release must match the observed event's frame, revision, navigation, normalized coordinates, buttons and modifiers. Missing current native records, layout changes, changed permissions, navigation, cancellation, synthetic events, unexpected packets and release mismatches fail the run. No uncertain action is retried.

The old5/current6 CPU counterexample uses the actual production pointer methods: production sends6, and acceptance requires independently supplied native6 plus freshly sampled pixels6. Missing6, same-navigation moved controls and enabled/admin/native-Ignore contradictions all refuse. CPU-authored event objects do not qualify browser `isTrusted` behavior or a real native GUI journey.

## Ownership and unchanged effects

The browser proof queue retains at most sixteen witnesses and 32 MiB of accounted PNG strings, ROI bytes and metadata; each PNG is at most 2 MiB. Whole-canvas captures remain bounded to four megapixels. Temporary encoding, the native audit ring and browser allocations are separate; this is not a total-memory guarantee. Proofs transfer after effects or in `finally`, are reasserted and written privately with mode 0600 and exclusive creation, then release their exact ownership. Failure retires listeners, records, gestures and queue resources without replacing the original acceptance error.

Home and synthetic reopening include calibration within their original total 20/30-second budgets. The original 15/90-second bilateral geometry predicates, reciprocal synthetic tone thresholds, ordinary mute restoration, unchanged seven baseline entities and twelve-second owned-profile cleanup are preserved. Observer B remains an ordinary owned participant. No hardware microphone or physical audibility claim follows from synthetic PCM.
