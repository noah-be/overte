# Native FBX empty records: conservative graph inspection

Substantial AI-assisted implementation. This runtime change is reviewed and integrated on the browser topic branch; actual live results are recorded separately.

Pinned native f91 FBXWriter::encodeNode writes FBXNode() after child lists and then fills even that empty record's absolute nonzero endOffset. Three's BinaryParser::parseNode treats endOffset zero alone as null; the native nonzero empty node is a zero-property unnamed metadata child, not a texture consumer. The inspector now skips only nodes with empty name bytes, propertyCount zero, property bytes zero and no children while building Objects/Connections metadata. Their original nodes/order remain present in derived serialization. Payload-bearing/child-bearing empty names, unknown connections, duplicate, nonnumeric, unsafe and negative IDs retain refusal. No graph budget, array bound or resource authorization is relaxed.
