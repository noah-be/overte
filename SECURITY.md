# Security policy for this experimental fork

## Supported versions

This hobby fork has no production-ready or security-supported release. Every
branch and artifact is experimental. Do not use valuable accounts, credentials,
private content, or sensitive devices without reviewing the relevant source and
platform documentation.

## Reporting a vulnerability

GitHub Private Vulnerability Reporting is enabled for this fork. Report a
concern that requires private handling through GitHub's
[private **Report a vulnerability** form](https://github.com/noah-be/overte/security/advisories/new).
Do not put credentials, private logs, device identifiers, account data, or
exploit material in a public issue, discussion, or pull request. The issue
tracker remains disabled.

For a concern that is safe to discuss publicly, open a
[draft pull request](https://github.com/noah-be/overte/compare) with a minimal
patch or reproduction and no credentials, private logs, device identifiers,
account data, or exploit material. Use the private form above for technical
details that should not be public.

The project is maintained without a response-time or remediation guarantee.
Reports should identify the affected fork revision, platform, reproduction
boundary, and whether the behavior also exists in unmodified historical code.

## Upstream boundary

This repository is maintained separately because it permits AI-assisted work.
Do not forward AI-assisted reports, patches, issues, or pull requests from this
fork to the official Overte repository. A vulnerability independently
reproduced in unmodified upstream code, without using AI-assisted fork
material, is subject to upstream's current security and contribution policies.
Reviewed upstream changes may enter this fork only through the one-way
[`upstream intake policy`](docs/UPSTREAM_INTAKE.md).
